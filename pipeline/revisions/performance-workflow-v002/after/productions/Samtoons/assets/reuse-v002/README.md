## Locate the actual selected source

The [video 002 native delivery guide](../../videos/002-how-arsenal-won-the-league/artifacts/delivery-v027/README.md) and its `edit.json` identify native file, scene, local range and film order. Treat those native snapshots as file-owned render inputs. Some authoring scripts depend on live registries and functions from earlier revisions; they are investigation references, not standalone rebuild commands. Read dependencies and destructive operations before reuse. Copy only the needed files into the new film, record source/hash and ownership, then save/reopen and run its intended next operation. Do not overwrite reviewed assets or regenerate accepted voice takes merely because an edit changes timing.

It does **not** establish portable character extraction, new expressions, head turns or performance quality.

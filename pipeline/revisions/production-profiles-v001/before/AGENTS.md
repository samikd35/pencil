# Working direction

- Use simple, expressive bodies. C / Elastic Comic is a proven animation reference, not a fixed visual identity. The user subsequently authorized recognizable player heads, hair, faces, kit details and changed proportions for Three Goals. One Heartbreak.
- Start from the current production's brief, selected references and existing work. Evaluate its actual shots and finished film through the shared workflow. Preserve `experiments/001_heavy_box/` and its delivery as historical evidence; its construction is an optional technical regression test when relevant, not a required starting point or style-quality benchmark.
- Keep character construction simple. Prioritize readable poses, continuous movement, contact, timing and expressive action. Each film's current user direction governs its visual style; preserve completed films and their assets.
- Keep football and educational topic exploration independent unless the user explicitly combines them.
- Football Shorts must retell verified real-world football incidents, famous moments or actual events. Preserve the important actions and outcome; distinguish visual exaggeration from historical fact. Choose the source event before developing its animated treatment.
- Educational animation may explain history, a mechanism or other factual information. It is not restricted to digital-life topics. Give each Short one clear question or learning outcome and verify the explanation.
- The current planning target is 32-60-second Shorts, with longer films considered after short-form production and audience tests. No niche has been finally selected.
- Use the existing production journal for actual work. No speculative pipeline framework or database is needed.
- Treat `PyBlend_Stickman_Starter/` as historical reference only. Its creative choices, unfinished platform plans and approval policies do not govern new Pencil work. Apply skills only when they fit the active basic stick-figure task.

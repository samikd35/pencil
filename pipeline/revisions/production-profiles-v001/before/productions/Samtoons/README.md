# Samtoons

Samtoons is the user's continuing production for similar animated videos, established on **14 September 2026**. The initial reference is 442oons' [2024 Clásico parody](https://www.youtube.com/watch?v=g3oku3-4-2A). Its direction is recognizable football caricature, simple expressive bodies, economical animation and complete comic stories built around verified events.

The recurring format is authorized; shared plot continuity and recurring fictional arcs are not selected. Each video should work independently. Football and educational exploration remain separate unless the user combines them.

**Comedy direction, clarified by the user on 14 September:** these are funny animated match highlights. Research establishes the event and supplies comic material; it does not require literal dialogue, behavior or reactions. Invent exaggerated conversations, impossible visual gags and character performances freely. The user specifically proposed Michael Oliver crying and apologizing to Carrick or United players. Such a scene is authorized parody, not a claim to have found a recording of it. Preserve a recognizable match and result while making entertainment the main experience. Research player, coach and club personas as well as match incidents; select recognizable habits, gestures and fan memes that can create recurring character behavior and payoffs, as the reference does with Yamal being treated as a child. Do not add every researched joke to every film.

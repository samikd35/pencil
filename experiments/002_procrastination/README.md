# Just One Thing — three-minute animatic

User-authorized story test, 10 September 2026. Original, wordless procrastination comedy with the existing C / Elastic Comic character. Target: exactly three minutes, with rough held poses, cuts, original music and sound effects. This is a pacing and comprehension test, not a finished animation.

Current delivery: [watch the animatic](artifacts/animatic-v001/just-one-thing-animatic.mp4), [editable Blender project with embedded audio](artifacts/animatic-v001/just-one-thing.blend), [review notes](review-v001.md), [timed storyboard](storyboard-v001.md). Final creative acceptance remains pending.

The task is hanging one picture on an existing hook. Measuring becomes checklist-making, then a planning board and preparations for preparations. The picture remains on the floor. The character eventually puts down the planning tools and hangs it. A slightly crooked result offers a final choice between another elaborate process and one small adjustment.

The previous experiment is a source asset, not a set of creative restrictions. We reuse the actual editable Blender character, palette and journal helper. Story timings and new props belong to this film. No new pipeline framework is introduced.

## Review questions

- Is the original task clear without reading an explanation?
- Do the detours get funnier or more consequential, rather than simply repeat?
- Where does attention drift over the full three minutes?
- Does the character's decision cause the ending?

Sources, builds, revisions and verification are recorded in `events.jsonl` using the existing journal helper with this folder as its root. User approval of production does not imply acceptance of the resulting film.

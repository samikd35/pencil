# Samtoons reusable selections v003

22 September 2026. This version retains every scoped construction, voice and film reference in [v002](../reuse-v002/README.md) and adds the user-selected [animated identity v002](../../branding/animated-v002/README.md) as the current channel default. [manifest.json](manifest.json) pins the exact files and hashes.

## Default branding selection

- Intro: `branding/animated-v002/samtoons-intro-1080p.mp4`, 3 seconds.
- Outro: `branding/animated-v002/samtoons-outro-1080p.mp4`, 12 seconds.
- Assembly: finish and approve an unbranded 1920×1080/24 fps episode master, then use `branding/animated-v002/assemble.py` to create a separate branded delivery.
- Placement: after the authored cold-open hook, or at 00:00 when there is no cold open; outro after the final story frame.

Copy this package's selected version/hashes into each new video's local assets before its affected review. Existing videos retain their earlier selections. A future update requires explicit adoption; it does not silently replace v002 in already completed films.

The standard clips need no episode-by-episode creative review when reused unchanged. Review a changed mascot performance, music mix, CTA, episode-specific prop/gag or different end-screen layout in that video's applicable checkpoints.

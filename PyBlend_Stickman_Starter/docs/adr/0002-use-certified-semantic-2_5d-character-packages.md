# Use certified semantic 2.5D Character Packages

Status: accepted

PyBlend's reusable animation authority is a versioned semantic 2.5D Character
Package: stable part and stroke owners, one fixed-length skeleton with shared
deformation geometry, explicit hidden art and local depth rules, reusable
pose-space corrections, and declared drawing or topology events. Compatible
same-view motion uses the skeleton plus cage/ARAP deformation; incompatible
silhouette, visibility, view, or topology changes use approved Alternate
Drawings. Generated full-body poses, TPS, and learned correspondence may propose
an Alternate Drawing, but it becomes authority only after explicit Creator
approval, package certification, and deterministic editable compilation. The package compiles
deterministically to editable Blender Grease Pencil assets and must pass the
two-character, four-motion-class scale matrix before Shot production resumes.
